# Agent instructions

Read `CLAUDE.md` in this directory. It is the main project guide for the architecture, game rules, socket contract, reconnect behavior, and commands.

Read `PRODUCT_PRINCIPLES.md` before changing gameplay, cards, layout, timers, player state, or connection behavior. Treat its rules as product requirements and acceptance criteria.

Do not weaken card visibility or connection recovery to simplify an implementation. Add focused tests for every affected product rule.

Do not change card artwork or unrelated styling unless the task requires it.
